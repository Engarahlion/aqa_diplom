## Запуск автотестов

**1. Открытие проекта в Android Studio**

- Открыть проект в Android Studio;
- Установить для проекта Java 11.0.28.

**2. Настройка эмулятора**

- Создать виртуальное устройство Pixel 8 Pro API 29;
- Запустить эмулятор.

**3. Запуск тестов**

- Нажать "Run 'app'";
- Нажать правой кнопкой мыши по каталогу app и выбрать "Run 'All Tests'".
